# VAIXLNS implementation boundary v1

This repository is treated as an executable constitutional fabric. Claims of implementation are separated from design claims.

## Required evidence per boundary

- V-IR: parser/semantic representation tests.
- Governance: authorization tests proving policy cannot be bypassed.
- VX: execution tests with stable identities.
- Ledger: append-only integrity and replay tests.
- CVL: deterministic verification tests.
- Evidence: hash/provenance tests.
- Recovery: failure and restart tests.

## Rule

A component is IMPLEMENTED only when executable code and a reproducible test exist in the repository. A README statement alone never changes status.
